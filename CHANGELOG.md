# 📜 Журнал змін (CHANGELOG)

Усі висвітлені зміни та оновлення проекту VotePulse фіксуються в цьому документі.

---

## [1.1.0] — 2026-10-26

### 🚀 Додано
- Додано захист від повторного голосування за IP-адресою та cookies.
- Додано можливість вивантаження результатів голосування у форматі PDF.
- Новий розділ у кабінеті користувача — «Архів опитувань».

### 🛠️ Виправлено
- Виправлено помилку з відображенням кирилиці в графіках результатів.
- Оптимізовано час завантаження головної сторінки на мобільних пристроях.

## [1.0.0] — 2026-10-01

### 🚀 Додано
- Перший офіційний реліз платформи VotePulse.
- Базовий функціонал створення публічних та приватних опитувань.
- Підтримка авторизації через Google та GitHub.
- Інтеграція REST API для отримання списку опитувань (GET /polls).
