# 🗳️ VotePulse — Платформа для голосования и опросов

## 📌 Описание проекта
**VotePulse** — это современная веб-платформа, предназначенная для быстрого создания, проведения и анализа публичных и приватных опросов и голосований в режиме реального времени. 

Проект решает проблему сложности организации прозрачного и оперативного сбора мнений в учебных заведениях, IT-командах и коммерческих организациях.

## 🚀 Основные функции
- **Создание опросов:** Поддержка одиночного и множественного выбора вариантов ответа.
- **Голосование в реальном времени:** Мгновенный подсчет и отображение результатов в виде диаграмм.
- **Приватность и доступ:** Возможность создания публичных опросов или голосований по уникальной ссылке/PIN-коду.
- **Защита от накруток:** Ограничение повторного голосования по IP-адресу или авторизованному аккаунту.
- **Экспорт данных:** Загрузка результатов голосования в форматах CSV и PDF.

## 👥 Для кого предназначен продукт?
1. **Студенты и преподаватели** — для проведения быстрой активности на лекциях, выбора старосты или темы проекта.
2. **IT-команды** — для проведения Scrum-палаток, голосования за архитектурные решения или выбора даты митинга.
3. **Организаторы мероприятий** — для сбора обратной связи от участников в режиме онлайн.
