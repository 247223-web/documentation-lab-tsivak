# 🗳️ VotePulse — Платформа для голосування та опитувань

## 📌 Опис проекту
**VotePulse** — це сучасна веб-платформа, призначена для швидкого створення, проведення та аналізу публічних і приватних опитувань та голосувань у режимі реального часу. 

Проект вирішує проблему складності організації прозорого та оперативного збору думок у навчальних закладах, IT-командах та комерційних організаціях.

## 🚀 Основні функції
- **Створення опитувань:** Підтримка одиночного та множинного вибору варіантів відповіді.
- **Голосування в реальному часі:** Миттєвий підрахунок та відображення результатів у вигляді діаграм.
- **Приватність і доступ:** Можливість створення публічних опитувань або голосувань за унікальним посиланням/PIN-кодом.
- **Захист від накруток:** Обмеження повторного голосування за IP-адресою або авторизованим акаунтом.
- **Експорт даних:** Завантаження результатів голосування у форматах CSV та PDF.

## 👥 Для кого призначений продукт?
1. **Студенти та викладачі** — для проведення швидкої активності на лекціях, вибору старости чи теми проекту.
2. **IT-команди** — для проведення Scrum-палаток, голосування за архітектурні рішення або вибору дати мітингу.
3. **Організатори заходів** — для збору зворотного зв'язку від учасників в режимі онлайн.
