# 📖 Інструкція користувача VotePulse

Ласкаво просимо до інструкції користувача сервісу VotePulse! Цей документ допоможе вам швидко розпочати роботу з нашою платформою голосувань та опитувань.

---

## 🚀 Як почати роботу з продуктом

1. **Реєстрація / Вхід:**
   - Перейдіть на головну сторінку платформи.
   - Натисніть кнопку **«Увійти»** та авторизуйтесь через Google, GitHub або за допомогою електронної пошти.

2. **Створення першого опитування:**
   - На панелі керування натисніть кнопку **«+ Створити опитування»**.
   - Введіть заголовок (наприклад: *«Вибір часу для дзвінка»*).
   - Додайте варіанти відповідей.
   - Вкажіть тип опитування (Один варіант / Множинний вибір).
   - Натисніть **«Опублікувати»**.

3. **Розповсюдження посилання:**
   - Натисніть кнопку **«Поділитися»**.
   - Скопіюйте пряме посилання або QR-код та надішліть його учасникам.

4. **Перегляд результатів:**
   - Перейдіть у вкладку **«Мої опитування»**.
   - Оберіть потрібне опитування — результати оновлюються автоматично в режимі реального часу.

## ❓ Часті запитання (FAQ)

### Q1: Чи потрібно реєструватися, щоб проголосувати?
**A:** Ні, голосувати можна без реєстрації за прямим посиланням, якщо організатор не увімкнув налаштування *«Тільки для авторизованих користувачів»*.

### Q2: Чи можна змінити свій голос після відправки?
**A:** За замовчуванням переголосувати неможливо, щоб уникнути фальсифікації. Однак создатель опитування може увімкнути цю опцію в налаштуваннях.

### Q3: Яка максимальна кількість учасників може голосувати одночасно?
**A:** Безкоштовний тариф підтримує до 500 одночасних підключень до одного опитування.

### Q4: Як захистити опитування від накрутки?
**A:** У налаштуваннях опитування ви можете ввімкнути обмеження за IP-адресою або вимагати обов'язковий вхід через акаунт Google.
